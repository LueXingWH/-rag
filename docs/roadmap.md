| 非目标 | 音频（已砍）、深度学习框架、八股、证书 | 见 §7 |

### 三个必须钉死的术语

- **用 AI 派 vs 做 AI 派**：前者要"能做出东西"，后者要"能理解并改进模型"。**两条路 90% 不重叠**，同时走等于都不走。
- **AI 产出物 vs 已证实能力**：AI 跑一整天产出的代码是**产出物**，一分能力都不会进你的账户。能力只在你**亲自读、亲自改、亲自调错**的那段时间里增长。
- **你亲手负责的部分**：一个项目里，只有你亲手做过并且能解释的那部分，才是你的。

## 3. 验收方法：向上追问三层（全文最重要的工具）

任何一行代码、任何一个设计，都按这个模板自检：

| 层 | 问题 | 合格标准 |
| --- | --- | --- |
| 第 1 层 | **这是什么？** | 能用一句话说清它在干什么 |
| 第 2 层 | **为什么这么写？** | 能说出替代方案，以及为什么没选它 |
| 第 3 层 | **如果去掉它 / 换掉它会怎样？** | 能预测后果，**或者说"我不知道，但我可以这样验证"** |

- 三层全过 = **已证实能力**
- 过不了第 3 层 = 正常，本项目大部分地方你也过不了——**但要能准确说出自己卡在哪一层**
- **"我不知道"是允许的答案；"装懂"不是。** 面试官追问两层就能分辨这两者。

## 4. 四年骨架

每个阶段只有一个问题：**这个阶段结束时，我手上多了什么别人能验证的东西？**

| 阶段 | 唯一产出目标 | 附带的必然要求 |
| --- | --- | --- |
| **大一**（现在 – 2027 夏） | **1 件"每一行都是我的"的项目** + GitHub 上 20 次以上有意义的 commit | Python 真功夫；数学/英语课考好（保留保研期权）；进一个实验室或社团 |
| **大二** | **1 个有真实用户的东西**（哪怕 10 个用户） | 工程能力：git 分支协作、测试、依赖管理、部署；一段实习（远程/小厂也算）或一次竞赛 |
| **大三** | **作品集 3 个项目，每个能讲 20 分钟** | 分岔：保研（科研 + 成绩）或秋招（实习 + 项目） |
| **大四** | 收口 | 暑期实习 offer / 夏令营入营 → 正式 offer 或录取 |

### 各阶段"纵深方向"的选择（大二再定，现在不选）

数据抓取工程 / AI 应用（Agent）/ 后端服务 / 安全。
**建议在大二上学期末再定**——你现在手上的信息不足以做这个选择，而早定会锁死。

## 6. 每天怎么过

```
45 分钟  Python 硬功夫（读文档 / 写小程序 / 读报错）
45 分钟  项目（20 天冲刺期内按 docs/interview-sprint-20d.md）
30 分钟  缓冲（不计入，超时就用它，不占用上面两格）
```

- **硬上限 2 小时/天**，每周留 1 天完全不学。
- **AI 可以替你写代码，但不能替你回答问题。** 交付前，每一行都要过"向上追问三层"。
- 时间口径可以只算你的交互时间；**能力口径只算你亲手碰过的部分**。

## 7. 非目标（现在不做，且要知道为什么不做）

1. **不学 PyTorch / 深度学习理论** —— 那是乙路线。选了甲，这一项的收益在四年内为负（占用你仅有的 2 小时）。
2. **不背八股** —— 背过的答案在追问两层后必然崩塌，且崩塌代价远大于说"不知道"。
3. **不做第三个 AI 生成的项目** —— 第三个不会比第一个更像你的。
4. **不为"简历好看"做任何事** —— 简历是能力的结果，不是原因。
