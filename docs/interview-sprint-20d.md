# 20 天冲刺：从"AI 生成物"到"我的作品"

> 起点 2026-09-23（D1）　终点 2026-10-12（D20，面试日）
> 目标：面向**人工智能创新协会**交付一个 AI 项目，并**能被追问三层**
> 时间：1.5 小时/天（硬上限 2 小时），每周 1 天完全休息

---

## 0. 这次冲刺要解决的真实问题

不是"缺项目"——你已经有一个了。真实问题是：

> **那条六步流水线（DSH 定方向/搭初版 → WorkBuddy 接数据 → 豆包读代码/管版本 → 手动贴实况），每一层你都往下讲不了第二层。**

所以 20 天的目标是一句话：**把流水线的关键环节，从"AI 做的"变成"我知道它是怎么做的"。**

### 交付物定义（不可谈判）

**新题目 + 真数据 + 你亲手负责的关键环节**

| 谁做 | 做什么 |
| --- | --- |
| **你亲手做**（这是本次唯一的能力增长点） | 确定数据源 → 发请求 → 解析 → 清洗 → 分块 → 出题 |
| **AI 可以做**（但要逐行过"追问三层"） | 检索、问答、Web 界面、打包 |
| **不许发生** | 让 AI 从零生成整个项目，你只看结果 |

### 硬性规矩

1. **D1 的自测题，不许问 AI。** 它只用来定位你的起点，问 AI 就废了。
2. **抓取脚本必须你手写。** AI 只准在你看不懂报错时**解释报错**，不准直接给代码。
3. **数据源只用公开渠道。** ⚠️ 不要抓校内需登录系统，**不要把接口细节、账号、内网数据放进公开仓库**。上一个项目那部分要清理。
4. **每周日休息。** 不是建议，是规矩。

## 第 1 周（D1–D7）：找到真实起点，把数据变成你的

| Day | 任务 | 完成标志 |
| --- | --- | --- |
| **D1** | ① 做下方自测 5 题（40 分钟，**不许问 AI**）② 定题目 + 定数据源 ③ 建目录、`git init` | 写下"我卡在第几题"，以及题目和数据源 |
| **D2** | 打开目标网页，**用 F12 看信息在哪一层**：HTML 里？JS 里？接口 JSON 里？ | 写出 3 句话：数据在哪、怎么拿、要哪些字段 |
| **D3** | **手写**第一个 `requests` 请求，把响应存成文件 | 文件躺在磁盘上；读得出状态码和编码 |
| **D4** | **手写**解析：从响应里取出你要的字段 | 打印出 10 条结构化记录 |
| **D5** | 存成 `jsonl` / `csv`，加错误处理（网络失败怎么办） | 脚本能重复跑，跑两次结果一致 |
| **D6** | 清洗 + 分块：去页眉页脚、按标题切、定块大小 | 产出 `data/corpus/` 下的真实语料 |
| **D7** | **休息** + 写 100 字："这周我实际做了什么、卡在哪" | 100 字 |

### D1 自测题（40 分钟，禁止问 AI）

1. 写一个函数，输入一个整数列表，返回其中所有偶数的平方组成的列表。
2. 写一个函数，读一个文本文件，返回它的行数。文件不存在时要给出友好提示。
3. 给你一段别人写的代码（含字典 + `for` + `if`），说出它最终打印什么。
4. 故意写一个会报错的程序（索引越界 / `KeyError`），**解释这段报错在说什么**，以及你会怎么定位。
5. 把上面几个函数放进 `mytools.py`，在另一个文件里 `import` 它并调用。

> 卡在哪一题，就是你 Python 的真实位置。**第 4 题是最重要的**——"看得懂报错"是你的第一个真门槛。

## 第 2 周（D8–D14）：接上 AI，但每一行都要能讲

| Day | 任务 | 完成标志 |
| --- | --- | --- |
| **D8** | **手写**一个最小检索：只用 BM25 思路，30~50 行，够用就行 | 给它一个问题，它返回最相关的 3 个块 |
| **D9** | 加一层问答。**AI 可以代笔**，但你今天必须逐行读懂 | 能说出每一行在干什么（第 1 层） |
| **D10** | 端到端跑通：问题 → 检索 → 回答 → 出处 | 命令行里能完整跑一次 |
| **D11** | **对照 `CONTEXT.md` 读自己的代码**，把术语一个个对上 | 每个术语你都能指着某一行代码说"就是这儿" |
| **D12** | **自己出 10 道评测题**（你懂南海校区，AI 不懂） | 10 道题，含 2 道故意问不到的 |
| **D13** | 跑这 10 道题，**用结果改一处代码** | 改前/改后的数字，各记一次 |
| **D14** | **休息** + 复盘：这周哪个改动是"看起来更周到"但没有用的？ | 一句话 |

> D12 是全程**最能体现你不可替代性**的一天。AI 能写检索，但**它不知道学生会怎么问**。

## 第 3 周（D15–D20）：变成能讲的东西

| Day | 任务 | 完成标志 |
| --- | --- | --- |
| **D15** | 做"**向上追问三层**"清单：把可能被问到的 10 个点写下来，标出你过得了第几层 | 10 条，每条标 1/2/3 层 |
| **D16** | **重写讲解稿**：以"我怎么指挥 AI 走完流水线 + 哪一步我亲手做 + 哪一步我不会"为主轴 | 3 分钟能讲完；八股砍到只剩你真懂的 |
| **D17** | 找一个"面试官"（人或 AI）**追问你 20 分钟**，录下来 | 一段录音；记下被问穿的点 |
| **D18** | 把被问穿的 3 个点弄懂（**只弄懂 3 个，不求全**） | 3 个点能过第 3 层 |
| **D19** | **全流程演练**：换一台机器/清空环境，从零跑一遍 | 现场不会翻车 |
| **D20** | 面试 | —— |

### D16 讲解稿主轴（诚实版，就讲这四句）

1. "这个项目我用 AI 跑的，具体流水线是这六步：……"（展示 `项目流程.txt`）
2. "其中**数据这一段是我亲手做的**：我怎么找源、怎么解析、怎么清洗。"（**这里讲最深，这是你的**）
3. "检索和问答这段是 AI 写的，我逐行读懂了其中 X 部分。"（**主动划边界**）
4. "有一处我用评测改掉了 AI 的方案：……"（**这一句最值钱**）

> **主动说"这是 AI 做的"，比被追问出来强一百倍。** 而且这个社团的门槛本来就是"用 AI 跑一个项目"——**你的诚实正好命中它的筛选标准。**

## 面试当天的话术原则

| 情况 | 怎么说 |
| --- | --- |
| 被问到完全不会的 | "这个我不会。我的理解到 X 为止，往下是 Y，我还没验证过。" |
| 被问到 AI 生成的部分 | "这段是 AI 写的，我读懂了 A 和 B，C 还没搞明白。" |
| 被问"你还做过什么" | 讲**接口逆向**那件事——那是你已证实的能力，含金量高于这个项目 |
| 被问八股 | 会的说会，**不会的直接说不会**。大一答不出来正常，装懂才致命 |
