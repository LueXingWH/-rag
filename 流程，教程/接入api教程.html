PowerShell 接入 DeepSeek API · 四步上手
每步做完按回车，黑底框里就是你要敲的命令；sk-你的key 换成你从 platform.deepseek.com 复制的那串。
1
打开 PowerShell
在文件管理器进到项目文件夹 C:\Users\26586\Desktop\大学\my__ai，按住 Shift + 在空白处右键 → 选「在此处打开 PowerShell 窗口」。
2
粘贴这一行，替换成你自己的 key，回车
PS> $env:DEEPSEEK_API_KEY = "sk-你的key"
什么都不输出 = 成功。引号要保留，key 写在引号里面。
3
验证 key 设上了没
PS> echo $env:DEEPSEEK_API_KEY
sk-你的key ← 原样打印出来就是成功
4
在同一个窗口里启动项目
PS> python ask.py --web --llm
浏览器自动打开，回答模式从「原文摘录」变成「大模型生成」。
想「设一次永久生效」？用 setx，别用 $env:
$env:XXX = "..." → 只对当前窗口有效，关窗口就没
$env:DEEPSEEK_API_KEY = "sk-..."
setx XXX "..." → 写入系统，新开窗口永久有效
setx DEEPSEEK_API_KEY "sk-..."
用了 setx 之后，必须关掉当前窗口、新开一个才能读到。
自检命令（key 设好后跑一下）：python ask.py --info —— 末尾出现 API 自检: 可用 就成了。
看到 HTTP 401 = key 打错；HTTP 402 = 余额不足；网络不可用 = 检查代理/防火墙。
